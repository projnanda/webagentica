# Single purpose

The extension has one purpose: to let a person **inspect, authorize and run the signed agent
packages that websites publish, in their own browser, under their own permissions**.

Every feature serves it: reading a page's agent-package links (finding agents), verifying a
package and showing who signed it (inspecting), the profiles, receipts and run plans (authorizing),
the background execution host with the person's models and records (running), the encrypted
store and the per-origin grants (keeping what running needs under the person's control). There
is no second purpose: no browsing data is collected, no page is modified, nothing is monetized.
