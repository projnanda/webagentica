# A deterministic execution of `meeting-agenda.agent.pkg`

These files are the complete artifact set one run produces, generated by the
**real** execution runner: the real signed artifact handed over an inherited
descriptor, the real `agentpkg.execution` child process, the real `Runtime` and
the real `Workflow` interpreter, the real `HostBridgeModelRouter` and the real
private execution protocol.

**The provider is the one thing that is not real.** A scripted stand-in answers
each rendered request with a document that satisfies the package's own schemas,
so the run is deterministic and spends nothing. Token counts, costs and
timestamps here are therefore synthetic; the structure, the audit chain, the
worker identities, the accounting arithmetic and the validation are not.

For a live run against a real model, see the [live acceptance
test](../../docs/package-execution.md#18-running-it) and the [milestone
report](../../docs/package-execution-report.md).

| File | Written by | What it is |
|---|---|---|
| `result.json` | the runner | the full execution report: status, output, final state, audit, usage, provenance |
| `audit.json` | the runner | 99 hash-chained events |
| `usage.json` | the runner | settled per-worker and global accounting |
| `provenance.json` | the runner | profile, interpreter, package id and digest |
| `agenda.json` | the runner | the **package-declared export** |
| `execution-begin.json` | this harness | what the runner reported after verifying the artifact and before running it |
| `execution-result.json` | this harness | the bounded result the parent receives over the protocol |

`run.json` is absent because the run record is written by the OpenClaw plugin
backend, which is not part of this harness.

What the run shows:

* 5 model calls — `plan` ×1, `perspective` ×3, `write` ×1 — from the graph, not
  from the runner;
* 5 workers, `Planner:1`, `Perspective:2/3/4`, `Writer:5`, with peak parallelism
  3, bounded by the package's own `max_parallel` and `max_instances`;
* 0 tool calls and 0 installed tool handlers;
* the package's assertions satisfied: the goal and duration are preserved and
  the agenda minutes sum to exactly 45;
* an audit chain that verifies.
