WebAgents is set up on this Mac

The native helper is installed. The installer log is /Library/Logs/WebAgents/installer.log.

1. Add the extension to Chrome

The Chrome Web Store listing is not public yet. Until it is, load the extension from a checkout of the repository:

  1. Build it: cd chrome-agent-browser && npm ci && npm run build
  2. Open chrome://extensions, turn on Developer mode, press Load unpacked and choose chrome-agent-browser/dist/extension.
  3. Check that the extension's ID reads @EXTENSION_ID@: the helper answers that ID only.

2. Unlock with the macOS keychain (optional)

  1. In the extension, open Settings → Security and set a passphrase (or unlock with yours).
  2. Under Unlock with the macOS keychain, press Turn on and allow Chrome to talk to the helper. The card then says keychain available.
  3. From now on, the Unlock sheet offers Unlock with the macOS keychain. Your passphrase keeps working, and removing the helper loses nothing.

The helper does three things only: it wraps and unwraps the key that opens your store, using an item in your login keychain, and it reports whether an Ollama you installed yourself is running. It never receives a provider key, a record or a package.

3. A model in this browser

In Settings → Models → In this browser, pick a model recommended for this Mac and press Download. The extension runs it itself, on your GPU, inside the browser: nothing to install and nothing leaves the browser. A model you download is a cache the browser keeps for this extension; you can delete it there, and uninstalling the extension removes it.

Ollama remains a route you may choose: it runs outside the browser's protection. Its setup (OLLAMA_ORIGINS) is under Other local routes in the getting-started guide and in Settings → Models.

Uninstall

sudo "/Library/Application Support/WebAgents/uninstall.sh" removes the helper, its Chrome registration and the helper's keychain item, and what an earlier version's Ollama option left (its login item and the extension's entries in OLLAMA_ORIGINS). Ollama, if you installed it, stays.
